# animal-crud-api
Simple CRUD API for Elephant Objects with JPA (Hibernate)

### Version
1.0.0

## Installation
- Get the project
    - clone
        ```
      git clone https://github.com/RishavIII/animal-crud-api.git
        ```
    - OR download zip.
- Open the project in VS Code.
- This project is built to run with jdk 21.
- [Dependencies](https://github.com/csc340-uncg/f25-jpa-crud-api/blob/7142cb123bc1444fb579ece9735062f1c3a15a86/pom.xml#L33) to JPA and Postgres in addition to the usual Spring Web. JPA handles the persistence, Postgresql is the database to be used.
- [`/src/main/resources/application.properties`](https://github.com/csc340-uncg/f25-jpa-crud-api/blob/6b2860c4ad01ca46b6b62852ca966bfadc8dfc6a/src/main/resources/application.properties) This file has the configuration for the PostgreSQL database to use for the API.
  - You MUST have the database up and running before running the project!
    - Login to your neon.tech account.
    - Locate your database project.
    - On the project dashboard, click on "Connect" and select Java.
    - Copy the connection string provided.
    - Paste it as a value for the property `spring.datasource.url`. No quotation marks.
- Build and run the main class. You should see a new table created in the Neon database.

## API Endpoints
Base URL: [`http://localhost:8080/elephants`](http://localhost:8080/elephants)


1. ### [`/`](http://localhost:8080/elephants) (GET)
Gets a list of all Elephants in the database.

#### Response - A JSON array of Elephant objects.

 ```
[
  {
    "elephantId": 1,
    "name": "Dumbo",
    "description": "Rescued Asian elephant",
    "gender": "Male",
    "age": 12.5
  },
  {
    "elephantId": 2,
    "name": "Maya",
    "description": "African savanna elephant",
    "gender": "Female",
    "age": 25.0
  }
]
```

2. ### [`/{elephantId}`](http://localhost:8080/elephants/1) (GET)
Gets an individual Elephant in the system. Each Elephant is identified by a numeric `elephantId`

#### Parameters
- Path Variable: `elephantId` &lt;Long &gt; - REQUIRED

#### Response - A single Elephant

```
  {
    "elephantId": 1,
    "name": "Dumbo",
    "description": "Rescued Asian elephant",
    "gender": "Male",
    "age": 12.5
  }
```

3. ### [`/name`](http://localhost:8080/elephants/name?key=jo) (GET)
Gets a list of elephants with a name that contains the given string.

#### Parameters
- query parameter: `key` &lt; String &gt; - REQUIRED

#### Response - A JSON array of Elephant objects.

```
[
  {
    "elephantId": 1,
    "name": "Dumbo",
    "description": "Rescued Asian elephant",
    "gender": "Male",
    "age": 12.5
  }
]
```

4. ### [`/gender/{gender}`](http://localhost:8080/elephants/gender/female) (GET)
Gets a list of elephants for a named gender.

#### Parameters
- path variable: `gender` &lt; String &gt; - REQUIRED

#### Response - A JSON array of Elephant objects.

```
[
  {
    "elephantId": 2,
    "name": "Maya",
    "description": "African savanna elephant",
    "gender": "Female",
    "age": 25.0
  }
]
```
5. ### [`/adults`](http://localhost:8080/elephants/adults?age=18) (GET)
Gets a list of elephants with an age meeting the Threshold.

#### Parameters
- query parameter: `age` &lt;Double&gt; - REQUIRED

#### Response - A JSON array of Elephant objects.

```
[
  {
    "elephantId": 1,
    "name": "Kavi",
    "gender": "Male",
    "age": 20.0
  },
  {
    "elephantId": 7,
    "name": "Rani",
    "gender": "Female",
    "age": 35.0
  }
]
```
6. ### [`/`](http://localhost:8080/elephants) (POST)
Create a new Elephant entry

#### Request Body
An elephant object. Note the object does not include an ID as this is autogenerated.
```
{
  "name":"Nandi",
  "description":"Young female elephant",
  "gender":"Female",
  "age":3.4
}
```
#### Response - The newly created Elephant.

```
  {
    "elephantId": 3,
    "name": "Nandi",
    "description": "Young female elephant",
    "gender": "Female",
    "age": 3.4
  }
```

7. ### [`/{elephantId}`](http://localhost:8080/elephants/3) (PUT)
Update an existing Elephant.

#### Parameters
- Path Variable: `elephantId` &lt;integer&gt; - REQUIRED

#### Request Body
An elephant object with the updates.
```
{
  "elephantId":3,
  "name":"Mister Updated",
  "description":"Updated description",
  "gender":"Male",
  "age":10.0
}
```
#### Response - the updated Elephant object.
```
{
  "elephantId":3,
  "name":"Mister Updated",
  "description":"Updated description",
  "gender":"Male",
  "age":10.0
}
```

8. ### [`/{elephantId}`](http://localhost:8080/elephants/3) (DELETE)
Delete an existing Elephant.

#### Parameters
- Path Variable: `elephantId` &lt;integer&gt; - REQUIRED

#### Response - the updated list of Elephants.
```
[
  {
    "elephantId": 1,
    "name": "Dumbo",
    "description": "Rescued Asian elephant",
    "gender": "Male",
    "age": 12.5
  },
  {
    "elephantId": 2,
    "name": "Maya",
    "description": "African savanna elephant",
    "gender": "Female",
    "age": 25.0
  }
]
```
